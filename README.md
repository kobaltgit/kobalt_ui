# Kobalt UI (`kobalt_ui`)

Официальная библиотека общих UI-компонентов и единый реестр проектов для промо-лендингов экосистемы **Kobalt Tools** (`MiniBin`, `Undoit`, `PolyShift`, `PeekIt`, `StashIt`, `PeekIt Plugins`).

## 📦 Компоненты

- **`KobaltFooter`**: Унифицированный 3-колоночный футер (Вариант 1) с автоматической взаимной перелинковкой всех утилит экосистемы, ссылками на исходный код (GitHub, Releases, Issues, License), кнопкой «Наверх ↑» и адаптивным стеком под мобильные экраны.
- **`KobaltNavBar`**: Стеклянная фиксированная шапка (Glassmorphism) с градиентной иконкой утилиты, бейджем версии, якорными ссылками навигации, сдвоенным переключателем языка `[ RU | EN ]`, кнопками GitHub и «Скачать».
- **`KobaltRegistry`**: Централизованный справочник утилит экосистемы Kobalt Tools с метаданными, описаниями на RU/EN и ссылками.

## 🚀 Подключение

В `pubspec.yaml` любого сайта экосистемы:

```yaml
dependencies:
  kobalt_ui:
    git:
      url: https://github.com/kobaltgit/kobalt_ui.git
      ref: main
    # Либо локально:
    # path: ../../kobalt_ui
```
